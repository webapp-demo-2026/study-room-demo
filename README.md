# ระบบจองห้องติวของคณะ (study-room-demo)

โครงงานอ้างอิงของรายวิชาการพัฒนาเว็บแอปพลิเคชัน ใช้เป็นตัวอย่างคำตอบของการบ้านบทที่ 8 — ข้อมูลทุกอย่างเป็นข้อมูลสมมติ

| หัวข้อ | รายละเอียด |
|---|---|
| ปัญหา | นักศึกษาไม่รู้ว่าห้องติวของคณะห้องไหนว่าง ไปถึงแล้วห้องเต็ม และเจ้าหน้าที่ดูแลห้องด้วยใบลงชื่อกระดาษ |
| ผู้ใช้หลัก | นักศึกษาผู้จอง, เจ้าหน้าที่ดูแลห้อง |
| Product Goal | นักศึกษาหาห้องติวว่างและจองให้ทั้งกลุ่มได้จากมือถือในไม่กี่นาที และเจ้าหน้าที่ดูแลการใช้ห้องทั้งคณะได้จากที่เดียว |
| สมาชิกและบทบาท | สมาชิก A, สมาชิก B, สมาชิก C (Scrum Master), สมาชิก D (Product Owner) |
