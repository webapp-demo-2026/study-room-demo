## Acceptance Criteria ของทุกเรื่องใน Sprint 1 (Given/When/Then)
### US-01 ลงทะเบียนและเข้าสู่ระบบ
- Given ยังไม่มีบัญชีที่ใช้อีเมล `praewa.s@student.example.ac.th` When ลงทะเบียนด้วยชื่อ รหัสนักศึกษา อีเมลนั้น และรหัสผ่าน Then ระบบสร้างบัญชีและพาไปหน้าค้นหาห้องว่าง (S-02)
- Given ผู้ใช้กรอกอีเมลที่ไม่ได้ลงท้ายด้วย `@student.example.ac.th` When กดลงทะเบียน Then ระบบไม่สร้างบัญชีและแสดง "ใช้อีเมลของมหาวิทยาลัยเท่านั้น"
- Given มีบัญชีแล้ว When เข้าสู่ระบบด้วยรหัสผ่านผิด Then ระบบแสดง "อีเมลหรือรหัสผ่านไม่ถูกต้อง" โดยไม่บอกว่าผิดช่องไหน
### US-02 ค้นหาห้องว่าง
- Given ห้อง A (จุ 6 คน) ว่างทั้งวันพฤหัสบดีและห้อง B (จุ 4 คน) ถูกจอง 13:00–14:00 When ค้นหาวันพฤหัสบดี 13:00–15:00 จำนวน 4 คน Then ผลค้นหามีห้อง A และไม่มีห้อง B
- Given ค้นหาจำนวน 8 คน When ไม่มีห้องที่จุ 8 คนขึ้นไป Then ระบบแสดง "ไม่มีห้องว่างในช่วงนี้" และเงื่อนไขเดิมยังอยู่ในช่องค้นหา
- Given ผู้ใช้เปิดหน้าค้นหาบนจอกว้าง 360 px When ผลค้นหาแสดง Then ทุกห้องแสดงชื่อ ความจุ อุปกรณ์ โดยไม่มีแถบเลื่อนแนวนอน
### US-03 จองห้องติว
- Given ห้อง A ว่างวันพฤหัสบดี 13:00–15:00 When ผู้จองยืนยันการจองช่วงนั้น Then ระบบบันทึกการจองและแสดงหน้าจองสำเร็จ (S-04) พร้อมรหัสการจอง
- Given ผู้จองเลือก 13:00–17:00 (4 ชั่วโมง) When กดยืนยัน Then ระบบไม่บันทึกและแสดง "จองได้ครั้งละ 1–3 ชั่วโมง"
- Given มีคนจองห้อง A 14:00–15:00 ไปแล้วระหว่างที่ผู้จองอยู่หน้าสรุป When ผู้จองกดยืนยัน 13:00–15:00 Then ระบบไม่บันทึกและแสดง "ห้องนี้เพิ่งถูกจองในช่วงเวลานี้" พร้อมปุ่มกลับไปค้นหา
### US-04 อีเมลยืนยัน
- Given การจองบันทึกสำเร็จ When ผ่านไปไม่เกิน 1 นาที Then กล่องอีเมลของผู้จองได้อีเมลที่มีรหัสการจอง ชื่อห้อง วัน และเวลา
- Given บริการอีเมลไม่ตอบ When การจองบันทึกสำเร็จ Then การจองยังอยู่ในหน้า "การจองของฉัน" และระบบลองส่งอีเมลใหม่
### US-05 ดูและยกเลิกการจองของตัวเอง
- Given ผู้จองมีการจองที่ยังไม่เริ่ม 2 รายการ When เปิดหน้า "การจองของฉัน" (S-05) Then เห็นทั้ง 2 รายการเรียงตามเวลาเริ่ม
- Given การจองเริ่มในอีก 3 ชั่วโมง When ผู้จองกดยกเลิกแล้วยืนยัน Then สถานะเป็น "ยกเลิกแล้ว" และค้นหาช่วงเวลานั้นเจอห้องว่าง
- Given การจองเริ่มในอีก 50 นาที When ผู้จองกดยกเลิก Then ระบบไม่ยกเลิกและแสดง "ยกเลิกได้ถึง 1 ชั่วโมงก่อนเวลาเริ่ม ติดต่อเจ้าหน้าที่"
- Given ผู้ใช้อื่นเปิดลิงก์ของการจองนี้ When กดยกเลิก Then ระบบปฏิเสธ (NFR-02)
